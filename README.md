# GhostTasking
This is the Github repo to reproduce all experiments, data, and graphs of the paper "Ghost tasking for parametrized Gaussian Processes solving linear differential equations" [DOI upon acceptance]
It is based on [PCGP](https://github.com/moserjo/PCGP) (physics-consistent Gaussian processes) and contains three experiments:

- `Experiment1_Tripendulum` — Tripendulum ODE system
- `Experiment2_Pedagogical` — Pedagogical PDE system
- `Experiment3_Magnetostatics` — magnetostatics PDE system: curl curl equation

Each experiment has the same layout:

```
ExperimentN_<name>/
  simulate_forward_input.py   # generates forward input_data/forward
  simulate_inverse_input.py   # generates inverse input_data/{standard,extra_npoints,known_u}
  training.py                 # shared training/eval helpers, not run directly
  input_data/                 # generated, see above
  optimisation/
    GT/, PIGP/, (GT_projective/ for Experiment2)
      main_forward.py         # runs forward problem
      main_inverse.py         # runs inverse problem
    output_data/              # generated by main_forward.py / main_inverse.py
  grid_evaluation/            # Experiment1 and Experiment3 only
    main_GT.py, main_PIGP.py, main_Bayes.py (Experiment1), main_complexityterm_*.py (Experiment3)
    output_data/              # generated by the main_*.py scripts
```

`computeralgebra/` holds Macaulay2/OreModules files used to derive the model
equations by hand — not part of the Python pipeline, run separately in those
tools. `graphical_abstract/` is a self-contained, smaller version of
Experiment 1 used for the paper's graphical abstract. `tables/` contains the files necessary to reproduce the tables for the ablation studies. 

## Setup

```
pip install -r requirements.txt
```

## File naming

Input/output files are `.npz`, named `Ex<N>_<method>_n<npoints>_sigma<sigma>_<run>.npz`:

- `N`: experiment number (1, 2, 3)
- `method`: `GT` (ghost tasking), `PIGP`, `GT_projective` (Experiment2 only), or `Bayes`
- `npoints`: number of observation points
- `sigma`: noise level, formatted `%.3f` (e.g. `sigma0.010`); 
- `run`: replicate index (0-9), omitted where there's only one run (forward
  problem, grid evaluation always reads/writes run `0`)

Forward-problem files drop `n`/`sigma`/`run` and are just `Ex<N>_<method>.npz`
for all three experiments.

Subfolders under `input_data/` and `optimisation/output_data/` (same names on
both sides) select the data variant:

- `standard` — default noise/point setup
- `extra_npoints_extra_sigma` — extra exact points for the control/ghost task
- `known_u_known_sigma` — control input treated as noise-free (Experiment1 only)
- `forward` — forward-problem data

`grid_evaluation/output_data/` (Experiment1 and Experiment3) uses its own,
unrelated naming since it stores hyperparameter-grid scans rather than single
runs:

- `<method>_n<npoints>_sigma<sigma>_fulln<n>.npz` — Experiment1 MLL/posterior
  grid (`n` = grid resolution per axis)
- `<method>_n<npoints>_sigma<sigma>_dataterm.npz` / `<method>_prior_sigma<sigma>.npz`
  — Experiment3 data-fit term / complexity term

## Running

Order: generate input data, then run optimisation (or grid evaluation), then
build graphs/tables. Run everything from the repo root or from inside the
experiment folder — the scripts resolve paths relative to their own file.

1. Generate input data:
   ```
   python Experiment1_Tripendulum/simulate_forward_input.py
   python Experiment1_Tripendulum/simulate_inverse_input.py
   ```
   No arguments; parameter grids (npoints, sigma, number of runs) are set at
   the top of each script.

2. Run forward/inverse optimisation. `main_inverse.py` scripts take positional
   CLI args (run `python <script>` with no args to see the exact usage string
   for that script); `main_forward.py` scripts take none — there's only one
   forward configuration per experiment:
   ```
   python Experiment1_Tripendulum/optimisation/GT/main_inverse.py <npoints> <sigma> <run> <mode>
   python Experiment2_Pedagogical/optimisation/GT/main_forward.py
   ```
   `mode` is one of the input/output subfolder names above
   (`standard`, `extra_npoints_extra_sigma`, `known_u_known_sigma`).

3. Grid evaluation (Experiment1 and Experiment3 only):
   ```
   python Experiment1_Tripendulum/grid_evaluation/main_GT.py <npoints> <sigma> <mode>
   python Experiment1_Tripendulum/grid_evaluation/main_Bayes.py <npoints> <sigma>
   ```

4. Graphs and tables, after the corresponding output_data exists:
   ```
   jupyter notebook Ex1_graphs.ipynb   # figures -> graphs/
   python tables/Ex1_metrics_table.py  # LaTeX table -> tables/Ex1_table.txt
   ```
